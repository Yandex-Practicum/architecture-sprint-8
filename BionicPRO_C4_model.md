## Уровень контекста (основные акторы и системы)

- Покупатель протеза — человек, который выбирает и оплачивает бионический протез через интернет‑магазин.
- Пилот протеза — пользователь, с мышц которого считываются миосигналы для управления протезом.
- Оператор производства — сотрудник, который использует CRM для получения информации о заказах и управления
  производством протезов.
- ML‑инженер — специалист по машинному обучению, который использует cli‑tool для работы с телеметрией и обучением
  ML‑моделей.

- BionicPRO (software system) — совокупность внутренних ИТ‑систем компании, обеспечивающих изготовление, настройку,
  эксплуатацию и анализ данных бионических протезов.
  Внутри BionicPRO выделены следующие ключевые контейнеры:
    - Программа в чипе протеза.
    - Приложение для донастройки протеза.
    - API.
    - База данных.
    - cli tool.

- Внешние для BionicPRO ИТ‑системы:
    - Интернет‑магазин (на базе Битрикс24).
    - CRM (на базе Битрикс24) и отдельная база данных CRM DB (например, Oracle Database 12).

***

## Интернет‑магазин и CRM

- Интернет‑магазин (Container: Битрикс24) — веб‑система, через которую покупатель выбирает протез, оформляет заказ и
  производит оплату.
- После оформления заказа информация передается в CRM (Container: Битрикс24).
- CRM хранит данные по заказам, клиентам и производству и взаимодействует с CRM DB — выделенной СУБД (например, Oracle
  Database 12), в которой размещаются данные CRM.
- Оператор производства работает с CRM, чтобы отслеживать текущие заказы и состояние производства протезов.

***

## Программа в чипе протеза

- Программа в чипе протеза (Software System, на ESP32) выполняет:
    - чтение данных с миодатчиков пилота протеза;
    - распознавание движений по миосигналам и их воспроизведение с помощью актуаторов;
    - обработку команд, приходящих из мобильного приложения, и реакцию протеза на эти команды;
    - передачу телеметрии и технических данных через встроенный 4G‑модуль во внутренние системы BionicPRO.

- Пилот протеза предоставляет миосигналы, которые считываются программой в чипе, и через свои мышечные сигналы управляет
  протезом.

***

## Приложение для донастройки протеза

- Приложение для донастройки протеза (Container: iOS, Android) — мобильное приложение, с помощью которого пилот может:
    - управлять протезом (отправлять команды на программу в чипе);
    - проводить донастройку алгоритмов распознавания движений;
    - инициировать передачу технической телеметрии и других данных через API.

- Приложение взаимодействует с программой в чипе двусторонне:
    - отправляет команды управления;
    - получает данные о состоянии протеза и результаты распознавания движений.

***

## Внутренний API и база данных

- API (Container: например, SpringBoot, ElasticSearch и др.) — серверная система BionicPRO, которая:
    - принимает данные и телеметрию от программы в чипе и мобильного приложения;
    - предоставляет интерфейсы для записи и чтения данных из внутренней базы данных BionicPRO;
    - служит основным точкой интеграции для cli‑tool и других внутренних сервисов.

- База данных (Container: PostgreSQL) — внутренняя БД компании BionicPRO, в которой хранятся:
    - телеметрия протезов и миосигналы, полученные в процессе эксплуатации;
    - конфигурации для донастройки протезов;
    - вспомогательные технические и аналитические данные, необходимые отделу ML и разработке.

- API записывает поступающие данные в эту базу данных и предоставляет интерфейсы для их выборки и анализа.

***

## cli tool и работа ML‑инженера

- cli tool (Container: например, SpringBoot, ElasticSearch и др.) — консольный инструмент, который подключается к
  внутренней базе данных BionicPRO.
- ML‑инженер использует cli tool для:
    - чтения и выгрузки телеметрии и миосигналов из БД;
    - подготовки данных и обучения моделей машинного обучения;
    - возможного обновления конфигураций или версий моделей, используемых программой в чипе.

***

## Основные потоки данных (кратко)

1. Покупатель протеза оформляет заказ и оплачивает его в интернет‑магазине; данные заказа попадают в CRM и далее
   доступны оператору производства.
2. Для пилота протеза изготавливают протез, в который встроен чип с программой и миодатчики; пилот управляет протезом
   своими мышечными сигналами.
3. Мобильное приложение для донастройки протеза обменивается командами и телеметрией с программой в чипе и отправляет
   данные во внутренний API.
4. API сохраняет телеметрию и прочие данные в базу данных BionicPRO.
5. ML‑инженер через cli tool получает доступ к данным в БД, подготавливает и обучает модели для улучшения алгоритмов
   распознавания движений.
6. CRM и CRM DB поддерживают процессы продаж и производства, а BionicPRO обеспечивает эксплуатацию протезов и анализ
   собранных данных.
