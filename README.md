Потом можно запустить уже docker-compose  из корня.
Вариант с PKCE в папке Task1. 
Для доступа к сервису отчетности из сервиса аутентификации реализовал token-exchenge.
Изначальный клиент reports-api в репозитории был настроен только на проверку токена (bearerOnly: true),
но это мешало настроить обмен токена, поэтому я его пересоздал.
Так же нужно прписать в hosts чтобы обмен токена работал корректно.
Иначе токен для клиента reports-frontend получит jwt токене "iss": "http://localhost:8080/realms/reports-realm",
а  при обмене с бэка сервиса авторизации в сети docker  адрес будет "http://keycloak:8080/realms/reports-realm"
и в обмене будет отказано. 
На реальном проде это настраивается иначе.
