1. Первое — зайти в папку airflow
   1. Запустить docker compose up -d
   2. Запустить скрипт db/init-db.sql, если он не запуститься сам
      1. Скрипт с созданием таблиц и схем и тестовыми данными для CRM и Телеметрии
2. Выйти в корневую папку
   1. Запустить docker compose up -d
   2. Запустить скрипт olap_db/init-db.sql, если он не запуститься сам
      1. Это скрипт с созданием таблиц и схем
3. Зайти в airflow, запустить ETL Dag
4. Зайди в фронт, авторизоваться, сгенерить отчет, скачать очет
