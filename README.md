Задание 1.1

Для повышения безопасности был добавлен централизованный Identity Provider (Keycloak), который поддерживает протокол OAuth2 с PKCE.

Клиентские приложения проходят аутентификацию напрямую через IdP.

Доступ к backend-сервисам осуществляется через Auth Gateway, который выполняет проверку access-токенов и обеспечивает централизованную авторизацию.

Keycloak может выступать Identity Broker и поддерживать интеграцию с внешними удостоверяющими службами разных стран.
