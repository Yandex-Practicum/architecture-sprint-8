# Отчёты: S3 и CDN

## Назначение

- Снижение нагрузки на OLAP: повторные запросы одного и того же отчёта отдаются из кеша (Redis) или с CDN (Nginx), без обращения к БД.
- Хранение сформированных отчётов в S3-совместимом хранилище (Minio) и раздача через Nginx с кешированием.

## Компоненты

- **Minio** — объектное хранилище (S3 API), порт 9001 (внутри сети — minio:9000).
- **reports-api** — при первом запросе читает отчёт из OLAP, сохраняет в S3, кладёт CDN-URL в Redis (TTL 5 мин). При повторном запросе в течение TTL отдаёт URL из Redis без обращения к OLAP и S3.
- **Nginx (cdn)** — reverse proxy на Minio, кеширует ответы по URI (порт 8082). Эмуляция CDN.
- **Redis** — кеш CDN-URL по user_id.

## Структура хранения в S3

- **Бакет:** `reports` (задаётся через `S3_BUCKET`).
- **Ключ объекта:** `reports/{user_id}/{period_from}_{period_to}.json`
  - Даты в ключе с подчёркиванием, например `2024_01_01_2024_01_07.json`, для корректного имени файла.
- Один объект на пользователя и период; при следующем запросе с теми же user_id и периодом тот же ключ перезаписывается актуальными данными из OLAP.

Такой ключ даёт быстрый доступ по user_id и периоду без листинга.

## Обновление кеша CDN

1. **Nginx:** кеш по `$uri`, `proxy_cache_valid 200 1d`. При обновлении отчёта в S3 (тот же URI) Nginx отдаёт старую копию до истечения 1d или до ручной очистки кеша.
2. **Варианты обновления:**
   - Уменьшить TTL в конфиге (например, `proxy_cache_valid 200 5m`) и перезагрузить Nginx.
   - Очистить кеш на диске: удалить содержимое тома `cdn-cache` (или каталога `proxy_cache_path`) и перезапустить контейнер `cdn`.
3. **Redis (URL кеш в reports-api):** TTL 5 минут. После ETL в течение 5 минут пользователь может получить старый URL; после истечения TTL запрос пойдёт в OLAP, отчёт перезапишется в S3 с новыми данными, в Redis попадёт новый URL.

Итог: данные в S3 обновляются при первом после ETL запросе (после истечения Redis TTL или при новом периоде). Кеш Nginx обновляется по TTL (1 день по умолчанию) или при очистке кеша.

## Переменные окружения (reports-api)

| Переменная    | Описание                                                              |
|---------------|-----------------------------------------------------------------------|
| S3_ENDPOINT   | Хост:порт Minio (например `minio:9000`)                               |
| S3_ACCESS_KEY | Ключ доступа Minio                                                    |
| S3_SECRET_KEY | Секрет Minio                                                          |
| S3_BUCKET     | Имя бакета (по умолчанию `reports`)                                   |
| CDN_BASE_URL  | Базовый URL CDN для выдачи клиенту (например `http://localhost:8082`) |
| REDIS_ADDR    | Адрес Redis для кеша URL                                              |

Если S3_* не заданы, reports-api работает без S3 (только OLAP, как раньше).
