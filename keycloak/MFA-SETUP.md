# Настройка MFA (OTP) в Keycloak

Чтобы вход в систему был возможен только после ввода одноразового пароля из Google Authenticator или FreeOTP, нужно включить OTP в поток аутентификации и при необходимости — обязательную настройку OTP для пользователей.

## 1. Поток аутентификации с обязательным OTP

1. Откройте **http://localhost:8080** → войдите как **admin** / **admin**.
2. Выберите realm **reports-realm**.
3. Меню **Authentication** → вкладка **Flows**.
4. Найдите встроенный поток **Browser** → в меню справа выберите **Duplicate**.
5. Задайте имя, например: **browser-otp** → **Save**.
6. В списке потоков откройте **browser-otp**.
7. В блоке **Forms** (подпоток) нажмите на него, чтобы раскрыть шаги.
8. В шагах подпотока **Forms** найдите **OTP Form** и в колонке **Requirement** смените значение с **Optional** на **Required** → **Save**.
9. Меню **Authentication** → вкладка **Bindings**.
10. В поле **Browser flow** выберите **browser-otp** вместо **browser** → **Save**.

После этого при каждом входе после ввода логина и пароля будет запрашиваться код из приложения (Google Authenticator или FreeOTP).

## 2. Обязательная настройка OTP для пользователей (Required Action)

Чтобы новые пользователи при первом входе обязательно настраивали OTP:

1. **Authentication** → вкладка **Required actions**.
2. Найдите **Configure OTP** и включите **Default action** (галочка).
3. **Save**.

Пользователи, у которых ещё не настроен OTP, при входе по потоку **browser-otp** будут перенаправлены на экран настройки OTP (сканирование QR-кода приложением), после чего смогут вводить коды при каждом входе.

## 3. OTP Policy (по желанию)

1. **Realm settings** → вкладка **Security defenses** → блок **OTP Policy** (или **Authentication** → **Policies** → **OTP policy** в зависимости от версии).
2. Можно задать:
   - **OTP Type**: One-time password (TOTP).
   - **Algorithm**: SHA1 (совместим с Google Authenticator, FreeOTP).
   - **Digits**: 6.
   - **Look Ahead**: 1 (допуск по времени).

По умолчанию Keycloak уже совместим с Google Authenticator и FreeOTP.

## 4. Проверка

1. Выйдите из Admin Console (или откройте режим инкогнито).
2. Перейдите на **http://localhost:3000** и нажмите вход (или сразу **http://localhost:8000/auth/login** для bionicpro-auth).
3. Введите логин и пароль пользователя realm (например **user1** / **password123**).
4. Должен появиться экран ввода кода OTP или экран настройки OTP (QR-код), если он ещё не настроен.
5. После настройки/ввода кода вход должен завершиться успешно; без кода OTP вход не должен проходить.
