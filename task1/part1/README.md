# Задача 1: Повышение безопасности системы - Решение для управления учетными данными пользователей

## Обзор

Это архитектурное решение решает проблемы безопасности, выявленные после недавней утечки данных в системе BionicPRO. Решение сосредоточено на улучшении механизмов аутентификации и авторизации, обеспечивая соблюдение международных норм защиты данных.

## Ключевые проблемы, решенные

1. **Уязвимость к взлому**: Предыдущая реализация OAuth2 Code Grant была скомпрометирована, что привело к несанкционированному доступу к данным.
2. **Требования к локализации данных**: Необходимость соблюдения различных законов о защите данных в разных странах.
3. **Унифицированное управление доступом**: Требуется централизованное, но распределенное управление учетными записями пользователей.
4. **Безопасность токенов**: Предотвращение прямого раскрытия токенов IdP frontend-приложениям.

## Архитектурное решение

### Добавленные компоненты

1. **BFF Auth Service** (Backend for Frontend Authentication Service)
   - **Технология**: Python/FastAPI
   - **Цель**: Действует как посредник между frontend-приложениями и инфраструктурой аутентификации
   - **Обязанности**:
     - Обрабатывает запросы аутентификации пользователей
     - Управляет жизненным циклом токенов (выпуск, валидация, обновление)
     - Предоставляет безопасные API-эндпоинты для frontend-приложений

2. **Keycloak** (Identity and Access Management)
   - **Цель**: Централизованный провайдер идентификации, поддерживающий множественные протоколы аутентификации
   - **Возможности**:
     - Поддержка OAuth2/OIDC
     - Мульти-тенантная конфигурация
     - Интеграция с внешними провайдерами идентификации
     - Поддержка социального входа

3. **LDAP** (Lightweight Directory Access Protocol)
   - **Технология**: OpenLDAP
   - **Цель**: Распределенное хранение данных пользователей
   - **Преимущества**:
     - Локальное хранение данных по странам/регионам
     - Соблюдение местных норм защиты данных
     - Иерархическая организация пользователей

4. **JWT Tokens Cache** (Хранение токенов)
   - **Технология**: Redis
   - **Цель**: Высокопроизводительное хранение и валидация токенов
   - **Особенности**:
     - Быстрое извлечение и валидация токенов
     - Автоматическое истечение токенов
     - Возможности распределенного кэширования

### Улучшения безопасности

#### 1. Унифицированное управление доступом
- **Реализация**: Данные учетных записей пользователей запрашиваются из внешних источников LDAP, расположенных в стране представительства компании
- **Преимущества**:
  - Обеспечивает соблюдение требований локализации данных
  - Снижает единую точку отказа
  - Поддерживает многорегиональные развертывания

#### 2. Безопасная обработка токенов
- **Реализация**: Паттерн BFF предотвращает прямое раскрытие токенов frontend
- **Поток**:
  1. Frontend отправляет запрос аутентификации в BFF Auth Service
  2. BFF Auth Service общается с Keycloak для аутентификации
  3. Keycloak валидирует учетные данные против LDAP
  4. BFF Auth Service выпускает собственные JWT-токены
  5. Токены кэшируются в Redis для производительности
  6. Frontend получает только токены, выпущенные BFF

#### 3. Поддержка множественных IdP
- **Реализация**: Возможности федерации Keycloak
- **Особенности**:
  - Поддержка множественных внешних провайдеров идентификации
  - Страновые сервисы аутентификации
  - Интеграция с социальными сетями
  - Поддержка протоколов SAML/OAuth2

### Поток данных

1. **Запрос аутентификации**:
   ```
   Frontend → BFF Auth Service → Keycloak → LDAP
   ```

2. **Выпуск токенов**:
   ```
   Keycloak → BFF Auth Service → Redis Cache → Frontend
   ```

3. **Доступ к API**:
   ```
   Frontend → API → BFF Auth Service (валидация токенов) → Redis Cache
   ```

### Преимущества соответствия и безопасности

- **Суверенитет данных**: Данные пользователей хранятся локально по юрисдикциям
- **Изоляция токенов**: Токены IdP никогда не доходят до frontend-приложений
- **Масштабируемость**: Распределенная архитектура поддерживает глобальное расширение
- **Аудитируемость**: Централизованное логирование и мониторинг через сервис BFF
- **Гибкость**: Легкая интеграция новых провайдеров идентификации
