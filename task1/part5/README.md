# Настройка MFA (OTP) в Keycloak

Настроить механизм OTP-аутентификации в Keycloak, сделать обязательный ввод одноразового пароля для всех пользователей, и убедиться, что вход возможен только после ввода OTP из Google Authenticator или FreeOTP.

## Тестирование входа
Пользователи из LDAP (john.doe, jane.smith, alex.johnson) логинятся с username = uid (например, john.doe), пароль = password.

При первом входе:
1. Введите username и пароль.
2. Система потребует настроить OTP: сканируйте QR-код в Google Authenticator/FreeOTP.
3. Введите первый OTP для подтверждения.

При последующих входах:
1. Введите username и пароль.
2. Введите OTP из приложения.

Вход возможен только с правильным паролем + OTP.

## Результат
MFA успешно настроена и обязательна для всех пользователей. Вход в систему требует двух факторов аутентификации.
